# Features 

- Event Discovery: Explore upcoming social events and discover exciting activities.
- Event Management: Create, edit, and manage events through an intuitive interface.
- User Authentication: Secure user registration and login with Better Auth and Google authentication.
- Event Participation: Join events and keep track of your registered activities.
- User Profiles: Manage personal profiles and stay connected with the event community.
